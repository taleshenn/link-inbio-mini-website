## 🚀 Tecnologias

Esse projeto foi desenvolvido com as seguintes tecnologias:

- HTML e CSS
- Git e Github
- Figma

## 💻 Projeto

O Mini Web Site é um agregador de links para usar como cartão de visitas em redes sociais que permitem adicionar links na bio.

- [Acesse o projeto finalizado, online](https://linkinbio-v1-tales-projects-6149a15d.vercel.app/)

## 🔖 Layout

## 📝 Aprendizado

Esse foi meu primeiro contato com HTML e CSS em muito tempo.
Aprendi muito sobre estruturas, semânticas e responsividade.
Identifiquei a componentização como um recurso importante para a arquitetura dos arquivos gerando uma melhor reusabilidade dos códigos.
Em CSS pude perceber a praticidade de se trabalhar com variáveis quando se trata de ajustar propriedades nos elementos da pagina.
